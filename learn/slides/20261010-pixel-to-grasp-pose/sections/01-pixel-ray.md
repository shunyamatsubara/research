VLM が返すのは [y, x] = [750, 625] のような 2D の数で、そのままではメートル単位の目標になりません。しかも単位も順番もモデルごとに違い、Gemini は [y, x] を 0–1000、Molmo は x, y を 0–100、RoboPoint は x, y を 0–1 で返します。

まず元の画像の幅 640 と高さ 480 を掛けて画素に戻します。u = 625/1000 × 640 = 400、v = 750/1000 × 480 = 360 です。順番を取り違えて [x, y] と読むと (480, 300) になり、有効な画素なので何も落ちずに、本来の点から 125 mm ずれた場所を指します。

画素が決まっても、まだ 3D の点は決まりません。その画素に写るものは、カメラの中心からその画素を通る 1 本の光線の上のどこかにあるからです。つまり 1 画素は 1 本の光線で、この光線が記事全体の道具になります。光線の傾きは、画素が画像の中心 (cx, cy) からどれだけ離れているかを fx で割ると決まります。例のカメラは fx = fy = 600、cx = 320、cy = 240 で、u − cx = 80 画素です。光線の傾きは 80/600 = 2/15 ≈ 0.133、v 方向は (360 − 240)/600 = 0.2 になります。

![Figure 1](#fig-1) — 画素 (400, 360) からカメラの中心を通る光線と、深度で止まる点を描いた図。強調は傾き 80/600 と、止まる点の X = 0.10 m。

この考え方を「ピンホールカメラモデル」、fx, fy, cx, cy を「内部パラメータ（intrinsics）」と呼びます。実際のレンズには歪みがありますが、D435 級の color では係数がほぼ 0 と報告されているので、ここでは無視します。
