# verify-G5: independent check of facts-G5.md (G401-G426)

Checked 2026-10-16 (clock on the checking machine read 2026-10-17). Method: every cited source was opened and the passage read. arXiv papers, the NDSS VehicleSec PDF and the J-STAGE PDF were downloaded and read as full text (pdftotext); NVD, CVE.org (cveawg) and Crossref were read as JSON; vendor and advisory pages (MiR, SICK CSAF, Siemens ProductCERT, CERT@VDE, JVN, Keyence, WHILL, NDSS program) and the GitHub RVD and Yarbo pages were read through the page-fetch tool, which returns a model-written extract, so quotes from those pages are as the tool returned them. The web search tool had no budget left, so no fresh open-web search was possible; "absence" statements (G410 "only", G426) were checked against the papers themselves, not against new searches.

No row in this file is a regulation date or a standard version, so the "dates changed by 2026" risk was checked on the advisory rows only (G413-G418, G420, G424, G425): NVD last-modified dates are 2026-06-17 for the 2020 to 2025 CVEs (metadata refresh, no change to the text read), JVN was updated 2026-10-07, and no vendor advisory had been superseded.

## Limits of this check

- No open-web search was possible (search budget exhausted), so G410 "only 2D-LiDAR attack paper" and the whole "What I could not find" section were not re-tested; they stand as the collector's absence claims.
- The GitHub RVD pages, the Yarbo README, MiR pages, SICK CSAF, Siemens, JVN and CERT@VDE pages were read through a fetch tool that returns an extract, not raw HTML. The G418 correction rests on that extract, repeated over three prompts with consistent answers; a person should glance at the README's "Scenario B" before the slide uses the credential wording.
- G414 and G413: the RVD pages still show status Open and mitigation "not disclosed". MiR's advisory index lists these 2020 CVEs but the index page carries no fix versions, so whether MiR fixed them is still not established.
