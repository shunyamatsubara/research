# Facts, angle C: boundaries (Bosch, Denso and peers as tier-1 suppliers)

Collected 2026-10-17 for the article on where an attacker can get into a learned-model-driven robot, AMR or car part, and which supplier controls can see each way in. Reader: tier-1 production, OT security and product/ECU security engineers.

## How to read this file

- One row per fact. Statements are facts only. Interpretation is kept in the notes and is short.
- Notes carry the exact quote behind each number or key claim. Quotes from files I downloaded and text-extracted myself (EUR-Lex PDFs, Kojima PDFs, Bosch certificate and advisory PDFs, arXiv PDFs, JAMA handbook, Continental report) were checked against the extracted text. Quotes from web pages read through the fetch tool were returned by that tool in quotation marks and were not re-checked against the raw page. Where the tool only returned a paraphrase, the note says "paraphrase" and there are no quotation marks.
- Each row is tagged for where it lands for a supplier: [factory], [product], [supply-chain] (model and data supply chain) or [general].
- Reliability: primary = the originating document; secondary = a report about it; hearsay = an attacker's claim or an unverified third-party claim.
- Verification 2026-10-16: every row was re-checked against the cited source by an independent pass; results and quotes are in verify-C-supplier.md. During that pass global.toyota and denso-wave.com were readable through curl; tuvsud.com, denso.com, fujitsu.com and EUR-Lex pages were not (EUR-Lex text was read from the EU Publications Office copy), so statements below that say a host was unreadable describe the original collection.
- Retrieval notes. These hosts refused the fetch tool with HTTP 403 and could not be read directly: denso.com, denso-wave.com, global.toyota, tuvsud.com, iso.org, openaccess.thecvf.com, and a copy of the ICCV paper at CVF. Where a row depends on one of these, the reliability is set to "secondary" and the note says "UNREAD primary; wording from a search-tool excerpt". Public PDFs and APIs (EUR-Lex, Kojima, Bosch, JVN, NVD, JAMA, VDA, Continental, arXiv) were downloaded and text-extracted, and I read the passages cited.
