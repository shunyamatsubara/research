Method: PDFs and web pages were downloaded and searched for the quoted passages (arXiv PDFs via pdftotext; vendor and standards pages as page text; EUR-Lex through the fetch tool because direct requests return an empty HTTP 202). arXiv submission and revision dates were checked against the arXiv API. Where a site blocked scripted requests, an alternate copy was used and is named in the evidence column (GitHub README via raw.githubusercontent.com, ISO catalogue via committee.iso.org, PMC paper via Europe PMC).
